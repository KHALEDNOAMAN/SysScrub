# SysScrub - Cleaning Guide\n\n## What SysScrub Cleans\n| Category | Items | Typical Space Saved |\n|----------|-------|-------------------|\n| Temp Files | Windows temp, user temp | 500MB - 5GB |\n| Browser Cache | Chrome, Firefox, Edge | 200MB - 2GB |\n| Windows Update | Old update files | 1GB - 10GB |\n| Recycle Bin | Deleted files | Varies |\n| Log Files | System and app logs | 100MB - 1GB |\n\n## Safe Cleaning\n- SysScrub only targets known-safe locations\n- No registry cleaning (avoids system instability)\n- Preview before delete option\n\n## Usage\n1. Run SysScrub as Administrator\n2. Select categories to clean\n3. Preview files to be removed\n4. Click Clean to free space\n\n## Building from Source\n`\ngit clone https://github.com/SametEge/SysScrub.git\ncd SysScrub\ndotnet build -c Release\n`
